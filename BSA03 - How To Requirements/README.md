# BSA03 — How To Requirements

**Тема:** Способы выявления требований

## Задание

Отработать техники выявления требований — ролевую игру, мозговой штурм и семинар — и свести результат в документ Vision с бизнес-требованиями.

**Бизнес-кейс:** Задача 2 — «Доставка заказов» (LMS).

## Приобретённые навыки

- Техники выявления требований: интервью, опрос, ролевая игра, мозговой штурм, семинар
- Фасилитация групповых сессий и протоколирование их результатов
- Преобразование «сырых» данных сессии в структурированные требования
- Подготовка документа Vision: цели, границы и бизнес-требования продукта
- Командная работа над общим набором проектных артефактов
