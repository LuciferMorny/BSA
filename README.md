# BSA — Business System Analysis

Учебные проекты по системному и бизнес-анализу (Школа 21). 16 модулей, каждый — законченный набор аналитических артефактов: от выявления стейкхолдеров и требований до проектирования интерфейсов, модели данных и REST-интеграции.

Каждая папка содержит только сданные артефакты и `README.md` с описанием задания, перечнем приобретённых навыков и таблицей «упражнение → результат».

## Бизнес-кейсы

Все модули выполнены на сквозных бизнес-кейсах:

| Кейс | Описание |
|------|----------|
| **CRM** — «Запись на стрижку» | Система онлайн-записи для сети барбершопов: выбор услуги, мастера и свободного слота, автоматические напоминания клиентам (Telegram / WhatsApp / VK / SMS), рабочее место менеджера, отчётность и отзывы |
| **LMS** — «Доставка заказов» | Стартап службы доставки: приём заказов от магазинов, распределение между курьерами, мобильное приложение курьера, диспетчеризация, интеграция с бухгалтерией |
| **Складское хранение** | Процессы складского учёта (модули по интеграции систем) |

Модули BSA07–BSA13 и BSA15 развивают один продукт (CRM барбершопа) последовательно — от пользовательских историй до спецификации REST API, что даёт сквозной пример полного цикла работы аналитика.

## Ключевые навыки

**Работа с требованиями**
Выявление требований (интервью, опрос, ролевая игра, мозговой штурм, семинар) · уровни и виды требований · модели as is / to be · документ Vision · функциональные требования · нефункциональные требования и их измеримые атрибуты · трассировка · управление требованиями и их регистрация

**Моделирование и нотации**
BPMN 2.0 · UML (диаграмма классов, Use Case) · DFD · swimlane · диаграмма и таблица состояний · ER-диаграмма · контекстная диаграмма · луковичная диаграмма

**Спецификация и документирование**
User Story и критерии приёмки (INVEST) · Use Case с основными, альтернативными и исключительными потоками · статусные модели и жизненный цикл сущностей · CRUD-матрицы · ролевая модель и матрица прав доступа (RBAC) · глоссарий проекта

**Данные**
Выделение сущностей предметной области · словарь данных · справочники и классификаторы · логическая модель данных · проектирование структуры под БД

**Интеграция**
Стили интеграции (файловый обмен, общая БД, RPC, обмен сообщениями) · карта потоков данных · мастер-системы и системы-получатели · REST API: ресурсы, HTTP-методы, коды ответов · маппинг данных · обработка ошибок

**Проектирование интерфейсов**
Ключевые сценарии ролей · карта экранных форм · wireframes · спецификация полей, источников данных и поведения контролов

**Качество**
Тест-дизайн: позитивные и негативные тест-кейсы · оценка результатов тестирования · ревизия и рецензирование моделей коллег (peer review)

**Командная работа**
6 из 16 модулей выполнены в команде (BSA03, 06, 09, 11, 13, 14), в том числе с распределением зон ответственности и код-ревью артефактов.

## Инструменты

MS Word и Excel — основной формат артефактов (спецификации, матрицы, словари данных). Диаграммы — BPMN, UML, DFD, ER, swimlane, state machine — приложены в PNG / PDF.
