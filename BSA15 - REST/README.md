# BSA15 — REST

**Тема:** Интеграция веб-сервисами REST

## Задание

Разобрать терминологию REST, актуализировать варианты использования под интеграцию, описать методы API и элементы запроса/ответа, выполнить маппинг данных и описать обработку ошибок.

**Бизнес-кейс:** Задача 1 — «Запись на стрижку» (CRM).

## Приобретённые навыки

- Проектирование REST API: ресурсы, HTTP-методы, коды ответов
- Описание методов, структуры запроса и ответа
- Маппинг данных между моделями взаимодействующих систем
- Обработка и документирование ошибок интеграции
- Актуализация вариантов использования под интеграционные сценарии
- Чтение и написание API-документации
