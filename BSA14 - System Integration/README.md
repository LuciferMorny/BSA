# BSA14 — System Integration

**Тема:** Интеграция ИТ-систем

## Задание

Выделить потоки данных между системами, определить мастер-системы и системы-получатели, согласовать словарь данных, описать сценарии интеграции и требования к объёму, частоте и срокам передачи.

**Бизнес-кейс:** Задачи 2 и 3 — «Доставка заказов» и «Складское хранение».

## Приобретённые навыки

- Стили интеграции ИТ-систем: файловый обмен, общая БД, RPC, обмен сообщениями
- Построение карты потоков данных между системами
- Определение мастер-систем и систем-получателей (подход MDM)
- Согласование словаря данных на стыке нескольких систем
- Требования к объёму, частоте и срокам передачи данных
- Описание сценариев интеграции, включая нештатные ситуации
