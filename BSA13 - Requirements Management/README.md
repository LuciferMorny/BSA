# BSA13 — Requirements Management

**Тема:** Управление требованиями, качеством, задачами

## Задание

Разложить требования по типам, зарегистрировать их и связать с задачами, написать позитивный и негативный тест-кейсы и оценить результат тестирования.

**Бизнес-кейс:** Задача 1 — «Запись на стрижку» (CRM).

## Приобретённые навыки

- Управление требованиями: типизация, регистрация, атрибуты, трассировка
- Связывание требований с задачами разработки
- Тест-дизайн: разработка позитивных и негативных тест-кейсов
- Оценка результатов тестирования и работа с дефектами
- Управление качеством и задачами в командном процессе
