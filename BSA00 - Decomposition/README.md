# BSA00 — Decomposition

**Тема:** Роль и функции ИТ-аналитика в команде разработки ИТ-систем

## Задание

Разобрать жизненный цикл разработки ИТ-систем и место аналитика в нём. Научиться выявлять источники информации, вести глоссарий проекта и строить декомпозицию системы, применяя её правила и виды.

**Бизнес-кейс:** Обе задачи: «Запись на стрижку» (CRM сети барбершопов) и «Доставка заказов» (LMS службы доставки).
