# BSA11 — User Interfaces

**Тема:** Проектирование пользовательского взаимодействия

## Задание

Выбрать форму представления продукта, спроектировать экранные формы справочников и классификаторов, разложить ключевые сценарии ролей по экранам, нарисовать wireframes и описать поведение контролов.

**Бизнес-кейс:** Задача 1 — «Запись на стрижку» (CRM).
