# BSA01 — Stakeholders

**Тема:** Заинтересованные стороны (стейкхолдеры)

## Задание

Выявить всех заинтересованных в системе лиц, разложить их по кругам влияния на луковичной диаграмме и описать их интересы, потребности и проблемы.

**Бизнес-кейс:** Задача 2 — «Доставка заказов» (LMS).

## Приобретённые навыки

- Идентификация заинтересованных сторон и построение каталога стейкхолдеров
- Луковичная диаграмма (Onion diagram): классификация стейкхолдеров по кругам влияния
- Анализ интересов, потребностей и проблем заинтересованных сторон
- Выделение ролей системы как основы будущей ролевой модели
- Перевод потребностей бизнеса в предпосылки требований к системе
