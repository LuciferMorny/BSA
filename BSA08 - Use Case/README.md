# BSA08 — Use Case

**Тема:** Сценарии использования

## Задание

Описать варианты использования (Use Case), их основные и альтернативные потоки, а также связи между вариантами использования.

**Бизнес-кейс:** Задача 1 — «Запись на стрижку» (CRM).

## Приобретённые навыки

- Спецификация Use Case: акторы, цели, предусловия и постусловия
- Описание основного, альтернативных и исключительных потоков
- Связи вариантов использования: include, extend, обобщение
- Выбор уровня детализации, достаточного для разработки и тест-дизайна
- Поддержание согласованности UC с моделью данных и ролевой моделью
