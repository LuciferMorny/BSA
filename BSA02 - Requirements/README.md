# BSA02 — Requirements

**Тема:** Требования

## Задание

Разобрать виды и уровни требований, описать модели as is и to be, построить контекстную диаграмму и проверить входные/выходные потоки данных.

**Бизнес-кейс:** Обе задачи: CRM (стрижка) и LMS (доставка).
