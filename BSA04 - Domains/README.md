# BSA04 — Domains

**Тема:** Предметная область и информационная модель

## Задание

Выделить сущности предметной области и действия над ними, проверить сущности по CRUD, составить словарь данных и построить логическую модель данных (ER-диаграмму).

**Бизнес-кейс:** Обе задачи: CRM (стрижка) и LMS (доставка).

## Приобретённые навыки

- Выделение сущностей предметной области и действий над ними
- Проверка полноты информационной модели по CRUD
- Составление словаря данных: типы, форматы, ограничения атрибутов
- Построение логической модели данных и ER-диаграммы, определение связей и кардинальности
- Работа с двумя разными предметными областями по единой методике
