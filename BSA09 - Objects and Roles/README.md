# BSA09 — Objects and Roles

**Тема:** База данных и словарь данных

## Задание

Описать объекты предметной области: их назначение, атрибуты и жизненный цикл, отдельно проработать справочники и собрать всё в диаграмму классов.

**Бизнес-кейс:** Задача 1 — «Запись на стрижку» (CRM).

## Приобретённые навыки

- Описание объектов предметной области: назначение, атрибуты, типы, ограничения
- Проработка справочников и классификаторов
- Построение диаграммы классов UML
- Проектирование словаря данных под структуру базы данных
- Итеративная актуализация модели по мере уточнения требований
- Командная работа над общей моделью данных
