# BSA05 — Diagrams

**Тема:** Модели и диаграммы

## Задание

Смоделировать требования графически: диаграмма потоков данных нулевого уровня, диаграммы «плавательные дорожки» (в базовом и расширенном виде), диаграмма и таблица состояний.

**Бизнес-кейс:** Обе задачи: CRM (стрижка) и LMS (доставка).
